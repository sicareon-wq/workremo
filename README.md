# WorkRemo

One-pager **HTML5 murni** (tanpa framework/CDN): panduan interaktif freelance remote **AI Trainer — IT & Non-IT**.

## Konten halaman
1. **Pengenalan** — apa itu AI trainer + perbandingan jalur IT vs Non-IT
2. **Skill Umum** — kompetensi per segmen dengan skill bar animasi
3. **Tujuan & Penerapan** — prospek karier dan platform yang dipakai
4. **Alur Belajar** — roadmap 6 tahap dengan SVG path yang tergambar mengikuti scroll

## Fokus fitur
- Alur: scroll-spy, progress bar baca, roadmap interaktif (klik node → detail)
- Motion: scroll-reveal, animated counter, skill bar, toggle segmen
- Progress roadmap tersimpan di `localStorage`
